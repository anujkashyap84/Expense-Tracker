# Smart Expense Tracker - Frontend

Frontend application for the Smart Expense Tracker built with **React.js, Vite, Tailwind CSS, and Axios**.

## 🛠️ Tech Stack

- React.js
- Vite
- Tailwind CSS
- React Router
- Axios
- Lucide React
- JavaScript

## 📦 Installation

### 1. Clone the Repository

```bash
git clone https://github.com/anujkashyap84/Expense-Tracker.git
cd Expense-Tracker
```

### 2. Go to Frontend

```bash
cd frontend
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Frontend

Run the development server:

```bash
npm run dev
```

The frontend will normally run at:

```text
http://localhost:5173
```

Open the URL shown in your terminal in a web browser.

## 🔗 Backend Connection

The frontend communicates with the backend API using Axios.

Backend API:

```text
http://localhost:4000/api
```

Make sure the backend server is running before using the application.

## 🚀 Run the Complete Application

### Terminal 1 - Backend

```bash
cd Expense-Tracker/backend
npm install
npm run dev
```

### Terminal 2 - Frontend

```bash
cd Expense-Tracker/frontend
npm install
npm run dev
```

Then open:

```text
http://localhost:5173
```
