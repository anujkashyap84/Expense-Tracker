# 💰 Smart Expense Tracker

Smart Expense Tracker is a full-stack personal finance management web application that helps users manage their income and expenses, monitor their financial activity, and understand their spending through an interactive dashboard.

---

## 🚀 Features

### 🔐 Authentication
- User registration and login
- Protected application routes
- JWT-based authentication

### 💵 Income Management
- Add income
- Edit income
- Delete income
- Categorize income
- View income history
- Export income data to Excel

### 💸 Expense Management
- Add expenses
- Edit expenses
- Delete expenses
- Categorize expenses
- View expense history
- Export expense data to Excel

### 📊 Dashboard
- Total balance
- Total income
- Total expenses
- Savings
- Savings rate
- Financial overview
- Spending by category
- Recent transactions
- Daily, weekly, and monthly views

### 📅 Transaction Date Management
- Past dates are allowed
- Today's date is allowed
- Future dates are disabled
- Transaction dates use Indian Standard Time (IST)

### 📱 Responsive Design
- Desktop-friendly interface
- Tablet support
- Mobile-friendly layout
- Responsive sidebar and navigation

### 🆘 Support
- Support center
- Frequently asked questions
- Helpful resources
- Contact support option
